# PetOS · 通用桌宠框架 · 设计文档

英文名：**PetOS** · 中文名：**我的宠物** · 仓库目录：`petos`。  
只提供玩法引擎与状态机；外观、动画、文案由用户自绘素材包驱动。框架不绑定任何具体宠物形象。

在线设计页（持续迭代）：以对话里的 PetOS 设计 Page 为准；本文件是仓库内可版本化的摘要。

## 技术架构（已锁定）

| 层 | 选型 |
|---|---|
| 壳 | Electron |
| UI | Vite + TypeScript + React |
| 立绘运行时 | **帧序列 PNG/WebP** + 动画 WebP + 静图；**Spine**（spine-player）为高质量动态；缺帧用 CSS 缓动 |
| 素材包 | 文件夹或 ZIP + 声明式 `manifest.json`（schema=1） |
| 持久化 | electron-store（或 userData JSON）；与素材包分离 |
| 明确不做 | SWF / Ruffle / 任何 Flash 运行时；不 eval 包内脚本 |

## 产品定位

可换皮的桌宠操作系统：内核管照料与人生模拟；皮囊完全交给创作者。官方可零自带角色立绘，只附占位剪影与素材包模板。

## 职责切分

| 层 | 框架提供 | 素材包提供 |
|---|---|---|
| 状态 | 饱腹/心情/精力/整洁数值与衰减 | 各档位姿态名、气泡文案 |
| 交互 | 摸、喂、玩、睡、面板逻辑 | 热区、反馈动画音效（可选） |
| 人生系统 | 成长/学习/旅行/职业/性格规则与存档 | 阶段立绘、地点皮、职业皮、语气表 |
| 物品 | 类型、效果表、背包规则 | 图标名称描述皮肤 |
| 场景 | 窝、桌面层级、拖拽窗口 | 背景窝外观 UI 主题（可选） |
| 叙事 | 无强制剧情 | 角色名、性格语气表 |

原则：不假设是什么动物；只假设可点击主体 + 命名姿态。

## 玩法内核（日常照料）

四状态：饱腹（降快，喂）、心情（摸/玩）、精力（睡）、整洁（打理，不影响存活）。  
流程：看见(idle) → 摸(pet) → 喂(eat) → 玩(换皮小游戏槽) → 歇(sleep)。  
危急只休眠可唤醒，不惩罚性死亡。一次照料 ≤30 秒。深度系统不做成每日任务墙。

## 成长系统 Growth

用「阶段」而不是无脑刷级：幼体 → 少年 → 青年 → 成年（可扩展暮年）。经验来自照料、学习、旅行、职业结算。

| 要素 | 框架 | 素材包可选 |
|---|---|---|
| 阶段 | stage id + 解锁条件 | 每阶段 idle / 体型缩放或换皮 |
| 属性 | 体力 / 智力 / 社交 / 幸运（软上限） | 属性影响的气泡差异 |
| 里程碑 | 首次摸、首次旅行等徽章 | 徽章图标 |
| 回退 | 长期忽视不掉级，只影响性格与心情 | — |

边界：成长永不「饿死重置」；可休眠、可变慢，不可因惩罚清档。

## 学习系统 Learning

短课时（约 3–10 分钟真实时间或等价挂机），结业给技能点或证书。技能是通用槽：语言、音乐、运动、手作……pack 只换课表皮与结业姿态。

- 同时进行的课程默认上限 1，避免面板过载
- 缺席 / 中断按性格系统记「陪伴缺口」，不扣光进度
- 结业可解锁部分旅行地点或职业门槛

## 旅行系统 Travel

宠物可「出门」一段时间（用户可设约 30 分钟–数天）。离家期间桌面只留明信片/空窝；回来带纪念品、见闻气泡、少量经验。

1. **出发**：选地点（框架通用地点 + pack 扩展）→ 确认离家时长  
2. **在外**：本地倒计时；需求衰减变慢或冻结；可看旅行日志  
3. **归来**：播 welcome 姿态；发纪念品；写一封短信（模板句 + pack 语气）

## 职业系统 Career

成年阶段可接「班次」：短班赚通用货币，长班更高收益但占用陪伴时间。职业是通用类型（看店、跑腿、创作、守卫……）。

| 规则 | 说明 |
|---|---|
| 班次 | 开始/结束明确；中途召回损失部分收益 |
| 货币 | 只买装饰 / 课程 / 旅行票；不卖官方角色 |
| 与性格 | 加班过多抬高「疏离」；适度工作抬「自立」 |
| 与学习 | 部分职业要求某技能证书 |

## 性格系统 Personality（陪伴模拟）

性格由「陪伴是否在场」慢慢塑形——类似长期疏于陪伴会形成特定应对方式。这是玩法隐喻：文案保持温柔，不猎奇、不羞辱玩家。

框架用慢滑动窗口记录陪伴信号，更新连续特质（依恋、自主、好奇、戒备等），对外只显示 2–3 个标签：

| 信号 | 举例 | 可能倾向 |
|---|---|---|
| 高频短陪伴 | 每天摸一下、喂一下 | 粘人 / 安心 |
| 低频长空白 | 连续多日无互动 | 疏离 / 自我安抚（旅行欲↑） |
| 承诺兑现 | 约好归来时间准时在 | 信任 |
| 承诺落空 | 班次/旅行逾期未归接 | 戒备；气泡更短 |
| 过度打扰 | 连点摸、强行召回 | 害羞 / 烦躁 cooldown |

- pack 提供各标签语气表与姿态变体；缺则用中性文案  
- 永远可被稳定陪伴慢慢「修好」；没有永久坏结局  
- 隐喻停在系统设计层，不做真实苦难题材宣传话术  

与四维需求正交：需求是瞬时状态，性格是长期倾向。

## 还可加什么（路线图候选）

1. **季节与纪念日**：节日气泡、领养日/周年小动画  
2. **窝与家园装修**：职业货币摆家具；纯装饰  
3. **信件与日记**：旅行/职业自动短日记；可导出分享  
4. **轻度社交**：交换明信片码 / 素材包；不做强制在线大厅  
5. **跨设备同步**：WebDAV 等用户自备网盘；存档与素材分离  
6. **专注模式**：减少气泡、关闭衰减提示，适合工作时挂机  
7. **创作工坊**：热重载预览、缺图清单、一键打包 zip  

建议优先级：M1 照料+动效 → M2 性格信号与成长阶段 → M3 学习/旅行/职业 → M4 家园与同步。

## 素材包约定

- 目录或 zip；根目录 `manifest.json`；schema=1  
- 脚底中心锚点；建议 1024² 透明正方形；格式限 PNG/WebP  
- 动效：`frames` / 动画 WebP / 静图 PNG / `spine`；缺动画用静图 + CSS 缓动（**禁止 SWF/Flash/Ruffle**）  
- Spine 目录与回退见 `docs/spine-pack.md`  
- MVP 必需：`meta.name`、`poses.idle`  
- 可选：`pet` / `eat` / `sleep` / `sad` / `hunger`、`voice`、`items`；后置 `stages` / `locales` / `jobs`  

```json
{
  "schema": 1,
  "meta": { "name": "我的小猫", "author": "you" },
  "poses": {
    "idle": { "src": "idle.png" },
    "pet": { "src": "pet.webp", "ms": 900 },
    "eat": { "src": "eat.png" },
    "sleep": { "src": "sleep.png" }
  },
  "voice": {
    "pet": ["呼噜……", "再摸摸"],
    "hungry": ["……肚子叫了"]
  }
}
```

## 缺省与回退

无包：几何占位宠 + 引导导入。缺姿态回退。坏图跳过。多包只激活一个。

## 安全

- 素材包只能资源 + 声明式 JSON，无可执行脚本  
- 不默认索取麦克风、摄像头、通讯录  
- 不做惩罚性死亡；危急只休眠  
- 性格隐喻不做成羞辱玩法  
- 远程包源需用户显式添加
