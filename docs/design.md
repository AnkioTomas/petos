# PetOS · 通用桌宠框架 · 设计文档

英文名：**PetOS** · 中文名：**我的宠物** · 仓库目录：`petos`。只提供玩法引擎与状态机；外观、动画、文案由用户自绘素材包驱动。框架不绑定任何具体宠物形象。



## 技术架构（已锁定）
| 层 | 选型 |
| 壳 | Electron |
| UI | Vite + TypeScript + React |
| 立绘运行时 | **帧序列 PNG/WebP** + 动画 WebP + 静图；**Spine**（spine-player）为高质量动态；缺帧用 CSS 缓动 |
| 素材包 | 文件夹或 ZIP + 声明式 `manifest.json`（schema=1） |
| 持久化 | electron-store（或 userData JSON） |

**明确不做**：SWF、Ruffle、任何 Flash 运行时；素材包无可执行脚本，框架不 eval 包内容。

## 产品定位
可换皮的桌宠操作系统：内核管饿、心情、摸、喂、玩、睡；皮囊完全交给创作者。官方零自带角色立绘，只附最简占位剪影与素材包模板。

## 职责切分
| 层 | 框架提供 | 素材包提供 |
| 状态 | 饱腹/心情/精力/整洁数值与衰减 | 各档位姿态名、气泡文案 |
| 交互 | 摸、喂、玩、睡、面板逻辑 | 热区、反馈动画音效（可选） |
| 物品 | 类型、效果表、背包规则 | 图标名称描述皮肤 |
| 场景 | 窝、桌面层级、拖拽窗口 | 背景窝外观 UI 主题（可选） |
| 叙事 | 无强制剧情 | 角色名性格语气表 |

原则：不假设是什么动物；只假设可点击主体 + 命名姿态。

## 玩法内核
四状态：饱腹（降快，喂）、心情（摸/玩）、精力（睡）、整洁（打理，不影响存活）。
流程：看见(idle) → 摸(pet) → 喂(eat) → 玩(换皮小游戏槽) → 歇(sleep)。
危急只休眠可唤醒，不惩罚性死亡。一次照料 ≤30 秒。

## 素材包约定
- 目录或 zip；根目录 manifest.json；schema=1
- 脚底中心锚点；建议 1024² 透明正方形；格式限 PNG/WebP
- 动效：`frames` 帧序列 / 动画 WebP / 静图 PNG / `spine` 骨骼；缺动画用静图 + CSS 缓动（**禁止 SWF/Flash/Ruffle**）
- Spine 目录与回退见 `docs/spine-pack.md`
- MVP 必需：meta.name、poses.idle
- 可选：poses.pet/eat/sleep/sad/hunger、items、voice.lines
- 缺姿态按回退表；绝不因缺图卡死

### manifest 示意
```json
{
  "schema": 1,
  "meta": { "name": "我的小猫", "author": "you" },
  "poses": {
    "idle": {
      "type": "frames",
      "frames": ["idle/f0.png", "idle/f1.png", "idle/f2.png"],
      "fps": 10,
      "loop": true
    },
    "pet": { "type": "webp", "src": "pet.webp", "ms": 900 },
    "eat": { "src": "eat.png" },
    "sleep": {
      "type": "spine",
      "skeleton": "spine/pet.json",
      "atlas": "spine/pet.atlas",
      "animation": "sleep",
      "loop": true
    }
  },
  "voice": {
    "pet": ["呼噜……", "再摸摸"],
    "hungry": ["……肚子叫了"]
  }
}
```

## 缺省与回退
无包：几何占位宠 + 引导导入。缺姿态回退。坏图跳过。多包只激活一个。

## 安全
素材包只能资源+声明式 JSON，无可执行脚本。不默认索权限。远程源需用户显式添加。



## 后期系统（文档占位 · 非 M1 实现）

> 以下系统已在产品设计画布中规划，**本仓库 M1 不实现代码**，仅作路线图锚点。实现前以画布「通用桌宠框架 · 设计文档」及后续系统页为准。

| 系统 | 一句话 | M1 |
|------|--------|----|
| **成长 Growth** | 长期养成曲线、阶段外观/能力解锁 | 不做 |
| **学习 Learning** | 可教导的小技能/反应，素材包可扩展题库 | 不做 |
| **出行 Travel** | 短时外出事件与带回物，桌面外叙事槽 | 不做 |
| **事业 Career** | 轻量「打工/表演」收益循环，不绑架每日必做 | 不做 |
| **性格 Personality** | **陪伴模拟**：关注 vs 忽视塑造特质（粘人/独立/傲娇等），影响气泡语气与小反应；非战斗数值 | 不做 |

原则：性格由照料密度与互动偏好慢慢成型，可缓慢变化，避免一次性定死；与四维需求正交——需求是瞬时状态，性格是长期倾向。

## 里程碑目标（本仓库先做 M1）
M1：四状态 + 摸喂睡 + 占位宠；manifest schema 1 校验与导入；空白模板。
M2/M3 可后续：热重载、物品包、主题、跨设备同步。
